# CureCheck (front-end demo)

Static demo of the CureCheck PRD. No build step or dependencies.

## Run in VS Code
1. File > Open Folder... and choose this `curecheck` folder.
2. Install the "Live Server" extension, right-click `index.html`, then "Open with Live Server".
   (Or just double-click `index.html` to open it in a browser.)

## Files
- `index.html`: page structure
- `style.css`: styles (light and dark mode)
- `script.js`: sample data, upload check, explainer, reminders, history, family access

## Notes
- All medical content is sample data. Nothing is uploaded or stored.
- Upload only checks file type and file name; real content checks, OCR, LLM, translation and login need a backend (FastAPI per the PRD).
- Hindi and Kannada text should be reviewed by native speakers before real use.
